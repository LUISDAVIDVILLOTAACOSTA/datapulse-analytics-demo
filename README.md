# 📊 DataPulse Analytics - Edición Evaluativa (Demo)

Este repositorio contiene el código fuente de la versión demostrativa de **DataPulse Analytics**, un software universal de analítica de datos interactiva automatizada, diseñado específicamente para optimizar la toma de decisiones y el procesamiento de reportes de PyMEs y agencias en Latinoamérica.

## 🛠️ Stack Tecnológico Utilizado
- **Lenguaje Principal:** Python 3.10+
- **Framework Web de Interfaz:** Streamlit (Arquitectura de Datos Dinámica)
- **Manipulación y Limpieza Lógica:** Pandas
- **Componentes de Maquetación Visual:** HTML5 / CSS Avanzado inyectado

## 🎯 Características Incluidas en esta Demo
- **Mapeo Inteligente Universal:** Interfaz flexible que permite mapear visualmente columnas de texto y números de cualquier archivo Excel (.xlsx) o CSV.
- **Procesamiento en Memoria RAM:** Cálculo instantáneo de indicadores globales como volúmenes operativos, sumas totales y promedios exactos.
- **Distribución Gráfica Estática:** Renderizado automatizado de gráficos de barras en alta definición para identificar cuellos de botella al instante.

## 🔒 Limitaciones de la Versión Demo vs Licencia Pro v2.0
Este repositorio sirve estrictamente como portafolio técnico y exhibición comercial. Las siguientes funciones corporativas avanzadas se encuentran restringidas:
1. **Filtros Dinámicos Multiselección:** Los selectores interactivos avanzados en la barra lateral izquierda están bloqueados.
2. **Diagnóstico Automático (Insights):** El módulo de alertas predictivas que calcula automáticamente máximos y mínimos de rendimiento requiere clave de licencia.
3. **Centro de Descargas Doble:** La exportación automática de informes ejecutivos formales en PDF y la descarga de bases de datos depuradas en Excel (.xlsx) están deshabilitadas.
